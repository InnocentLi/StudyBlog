# 06. 泛型&通配符详解

## 概述

泛型是 Java 1.5 引入的一个特性，可以在编译时期进行类型检查，避免了 ClassCastException 运行时异常。
通配符是泛型中的一个高级特性，提供了更灵活的类型约束方式。
